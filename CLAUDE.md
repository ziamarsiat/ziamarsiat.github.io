# Instructions projet

## Langue
Toujours répondre en français.

## Stack
- React + Vite
- CSS vanilla (pas de framework CSS)

## Commandes
- Dev : `npm run dev`
- Build : `npm run build`
- Lint : `npm run lint`

## Structure
- Composants React dans `src/components/`
- Pages dans `src/pages/`
- Assets dans `src/assets/`

## Conventions
- Noms de composants en PascalCase
- Fichiers CSS associés au composant (ex: `Header.jsx` + `Header.css`)
- Messages de commit en français
